## Компиляция и запуск (Linux)

Все лабораторные работы компилируются с помощью команды:

```bash
javac -encoding UTF-8 -d out src/*.java
```

После компиляции запускаете нужный вам файл(Зачастую файл Main).

```bash
java -cp out Main
```
